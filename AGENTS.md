# AGENTS.md — проект Task

## Область проекта
Работать только с продуктом Task: Windows desktop-органайзер для локальной сети компании.

## Канонические источники
1. `sources/concept/Task_Concept_Final.txt` — бизнес-требования.
2. `sources/stage_1/architecture_organizer.md` — архитектура Этапа 1.
3. `sources/stage_2_2/Organizer_Stage2_Technical_Specification_2.2.zip` — технический контракт.
4. `sources/stage_3_4/Organizer_Stage3_Final_Baseline_3.4.zip` — UX baseline.
5. `sources/stage_4_1_1/Organizer_Stage4_PRD_Candidate_4.1.1.zip` — кандидат PRD.

## Правила
- Не использовать файлы, память или решения из других проектов.
- Не читать соседние проектные папки без прямой команды.
- Не изменять содержимое `sources/`.
- Все рабочие изменения выполнять в `work/`.
- Все итоговые артефакты помещать в `outputs/`.
- Старые, сомнительные и конфликтующие файлы помещать в `archive/quarantine/`.
- При противоречии соблюдать порядок канонических источников выше.
- Не менять бизнес-требования без явного решения пользователя.
- Для каждого итогового пакета создавать manifest, версию, SHA-256 и validation report.
- Не объявлять этап завершённым без фактической проверки артефактов.
