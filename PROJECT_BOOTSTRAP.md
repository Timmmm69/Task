## Продукт
Windows desktop-приложение для задач, проектов, календаря, контактов,
уведомлений и каталога ссылок на локальные/сетевые файлы.

## Архитектура
- Windows desktop client
- локальный backend
- PostgreSQL
- локальная сеть компании
- SMB/NAS/локальные пути файлов
- сервер является источником истины
- read-only при временной потере сервера в MVP
