# Manifest

Пакет: `20260825_task_wpf_visual_foundation_0.1.0`

Версия: `0.1.0`

Scope: validation package `PRODUCTION-WPF-VISUAL-FOUNDATION-01`.

`MANIFEST.sha256` контролирует все файлы пакета, включая evidence, кроме самого
`MANIFEST.sha256`. Пути записаны относительно каталога пакета и используют `/`.

Проверка выполняется скриптом `Verify-Manifest.ps1` из каталога пакета. Скрипт
проверяет формат каждой строки, отсутствие пропущенных/лишних файлов и SHA-256
каждого контролируемого файла.
