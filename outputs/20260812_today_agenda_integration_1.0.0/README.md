# Today agenda integration package

Version: 1.0.0  
Base: `origin/main` at `aa9b56d77f27651d2efb8cba5d08a41389840cda`

## Included product changes

- compact agenda replaces the hour grid only in the central Today surface;
- scheduled tasks sort by start time, priority, then stable original order;
- untimed tasks sort by priority while retaining equal-priority order;
- the completed section is collapsed by default;
- selecting a row updates the existing task-details panel;
- creating an untimed task places it in the untimed agenda section.

## Deliberately excluded

- copied legacy prototype files;
- Gate 5.6 runtime, evidence, reports and `dist/` output;
- changes to the global header, navigation, right-side panel and calendar surface.
