# QA-04 — внутренний usability review и disposition findings

Дата review: 11 сентября 2026 года. Reviewer: внутренний QA (Codex). Участие заказчика не
требовалось. Проверялся fresh-run Release WPF с профилем `qa03-deterministic-v1`.

## Audit scope

Проверены первое подключение и основной экран на 100/125/150/200%, а также девять групп
критических сценариев: Сегодня, создание/редактирование задачи, конфликт, календарь, проекты,
каталог/контакты, поиск, уведомления и offline/reconnect. Для каждого шага screenshot был создан
и визуально просмотрен в текущем run; поведенческий результат подтверждён UIA assertions.

## Общий результат

Все критические сценарии завершены успешно. Информационная архитектура последовательна,
основная навигация стабильна, destructive/data-loss исходов нет, offline-состояние объясняет
ограничение записи и сохраняет подтверждённые данные. На 200% интерфейс переходит к прокрутке и
collapse detail pane, сохраняя критические элементы.

## Retest и regression

Production-код не исправлялся в рамках этого review: два наблюдения приняты, два отложены.
Поэтому fix-specific retest не применим. Вместо него выполнен полный свежий regression run:

- 12/12 critical UI assertions — PASS;
- 8/8 DPI cases — PASS;
- keyboard `Tab`/`F6` и UIA Value/Invoke/Selection — PASS;
- 7/7 focused desktop tests — PASS;
- изолированный runtime удалён, исходный Desktop AppData восстановлен — PASS.

## Evidence limits

Screenshots подтверждают layout, reflow, readable states и отсутствие видимых блокеров, но сами
по себе не доказывают assistive-technology compatibility. Narrator исключён из acceptance scope;
пакет не заявляет полное соответствие WCAG или сертификацию экранного диктора. Физический
mixed-monitor переход остаётся deployment smoke.
