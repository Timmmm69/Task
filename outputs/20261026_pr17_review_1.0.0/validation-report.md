# PR 17 — независимая Windows-проверка, 1.0.0

Результат: локальные проверки PASS. Решение о merge принимается отдельно после проверки актуального CI и неизменности head.

Проверена интеграция с актуальным main (28aa850); исходная ветка отставала на 34 коммита. Бизнес-логика и исходные пути привязок повторений сохранены.

Исправлены три дефекта ресурсов WPF:
- StaticResource внешнего стиля кнопки внутри шаблонов календаря/DatePicker вызывал XamlParseException. Использован DynamicResource.
- Стиль фокуса CalendarDayButton/CalendarButton мог содержать UnsetValue и аварийно завершал Task при нажатии стрелки. Использован DynamicResource; тест проверяет реальные значения FocusVisualStyle всех дней и месяцев.
- Адаптивная компоновка зависела от конвертера App.xaml. Конвертер объявлен локально, по существующему паттерну Calendar.Forms; тест NativeCalendarUsesSharedPickerAndContactFallback проходит.

Windows Release build: 0 ошибок; 2 существующих предупреждения xUnit в desktop-тестах. Форматирование всего решения, git diff --check, аудит зависимостей, границы проектов, статическая security-проверка и secrets/TLS contract проходят.

Итоговые тесты: Task.Desktop.Tests 1921/1921; Task.Tests с реальным PostgreSQL 16 — 914/914; Task.ServiceHosts.Tests — 671/671. Итого 3506 PASS, 0 FAIL, 0 SKIP. TRX включены.

В настоящем Task.Desktop на изолированных локальных данных проверены открытие календаря и повторений, пустой список, заполнение названия, предпросмотр ближайших дат, сохранение серии, появление созданной задачи, сохранность после перезапуска, открытие DatePicker, Right + Enter (26 → 27 октября), Escape и переход к выбору месяца.
