# API-04 — API модулей продукта

Версия: 1.0.0. Дата проверки: 2026-09-04. Схема PostgreSQL: 10.

Проекты, CRM, файловый каталог, поиск, уведомления, архив/корзина и настройки доступны через существующий авторизованный API host. Реализация проверена и подготовлена к публикации в main; факт публикации определяется историей Git. Развёртывание на сервере заказчика не выполнялось.

Контракт и эксплуатационные границы: `work/production/docs/task-product-api.md`. Каталог маршрутов: `ProductApiRoutes.All`. Для обновления сервера сначала выполнить offline migration 10, затем применить обновлённые runtime grants.

Пакет содержит validation report, результаты трёх тестовых сборок в TRX, manifest с SHA-256 исходных файлов и контрольные суммы файлов самого пакета. `manifest.json` фиксирует базовый commit реализации. Хеши исходников вычислены после нормализации CRLF в LF (как текстовые Git blobs); хеши артефактов — по точным байтам. Локальный `.gitattributes` пакета защищает его контрольные суммы от преобразования переводов строк.

Проверка: 1 435 тестов успешно, 0 ошибок, 0 пропусков; реальные PostgreSQL-сценарии выполнялись на отдельном кластере 16.14 под ограниченной runtime-ролью. Security gate, форматирование и архитектурные границы пройдены. Подробности и ограничения — в `VALIDATION_REPORT.md`.

API-04 не означает готовность всего продукта: UI, серверные network-probe/purge/delivery workflows и полная реализация каждого endpoint из OpenAPI 2.2 в этот пакет не входят. Нереализованные действия не возвращают фиктивный успех.
