# Task secure API foundation 0.6.0

This package records the approved first secure identity/organization/API foundation increment.

It provides a fail-closed ASP.NET Core API boundary, a server-derived request-identity contract, stable permission-code validation, sanitized correlated Problem Details, and focused tests. It deliberately does **not** provide user provisioning, identity/audit migrations, password storage, login, refresh, JWT validation, authorization grants, Task CRUD, or a production-authentication readiness claim.

See `MANIFEST.md`, `SHA256SUMS.txt`, and `VALIDATION_REPORT.md`.
