# Calendar product completion — 1.0.0

PROD-03: календарь показывает и изменяет расписание.

Добавлены режимы дня и месяца к недельному календарю, выбор даты и навигация по периодам. Многодневные события отображаются во всех затронутых днях. Детали, конфликты и права доступа сохранены.

Редактор повторяющихся задач поддерживает ежедневные повторы, рабочие дни, недельные, месячные и годовые правила, окончание по дате или количеству, предпросмотр, изменение отдельного экземпляра, последующих экземпляров или всей серии, приостановку, возобновление и отмену. Серии и экземпляры сохраняются в PostgreSQL, операции защищены версиями и ключами повторного запроса. Worker расширяет горизонт активных серий.

Редактор события позволяет добавлять и удалять сотрудников и контакты, менять роль и ответ участника. Обновление события без массива участников сохраняет существующий состав; явный пустой массив очищает его.

Production-код находится в `work/production`. Перед запуском обновлённого API требуется применить миграцию `008_calendar_recurrence` штатным Task.DatabaseMigrator. Затем обновить API, Worker и Desktop.

Проверки и границы контракта описаны в VALIDATION_REPORT.md и CONTRACT_NOTES.md. Пакет проверяется скриптом Verify-Manifest.ps1.
