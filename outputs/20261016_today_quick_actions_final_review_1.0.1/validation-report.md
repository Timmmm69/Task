## Найдено и исправлено

1. После очистки даты планирования и создания нового экрана календарная запись deadline снова возвращала задачу в блок без времени. Теперь каждый загруженный Task сверяется с подтверждённым DTO, включая отсутствие планирования. Deadline не меняется; задача остаётся в очереди.
2. Старые задачи с UTC-началом и длительностью через полночь могли исчезать из сегодняшнего плана, если Calendar API не возвращал запись. Теперь длительность и день восстанавливаются из Task DTO независимо от deadline.
3. Object-scope 403 для смены статуса одной задачи отключал статусы остальных. Отказы теперь сохраняются отдельно по ID задачи; другие разрешённые задачи остаются доступны.

Все три сценария сначала воспроизведены падающими тестами (2 ошибки проекции, 1 ошибка разрешения), затем проверены после исправлений. Технический API, БД, permissions, бизнес-статусы, Personal и посторонние пользовательские изменения не менялись.
