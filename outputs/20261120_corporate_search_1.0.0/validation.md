# Проверка корпоративного поиска Task

Версия 1.0.0, 20 ноября 2026 года.

## Выполнено

- Release-сборка Task.Desktop прошла без ошибок и предупреждений. Проверка форматирования затронутых C#-файлов и `git diff --check` прошли.
- Все 113 целевых desktop-тестов прошли. Покрыты поиск, смена прав, безопасное открытие объектов, связи, палитра команд, личный поиск, общие шаблоны и свойства UI Automation.
- На настоящем корпоративном MainWindow WPF с демонстрационным клиентом проверены фокус поля, Tab, запуск через Enter, группировка, фильтрация загруженной страницы без нового запроса поиска и догрузка при активном фильтре. Кнопка результата открыла конкретную запись каталога по её ID.
- Проверены начальная подсказка, редактирование запроса перед отправкой, ожидание ответа, пустой результат, ошибка ответа, недоступность сервера, отзыв прав и истечение сессии. При потере связи подтверждённые результаты остаются видимыми. При отзыве доступа список очищается.
- Визуально проверены окна 1320×880 и 920×840 DIPs. При 800×480 DIPs проверены прокрутка к результату и открытие. Снимки содержат клиентскую область настоящего окна WPF с вымышленными данными.

## Границы проверки

- Отдельный снимок «Сегодня» отсутствовал во вложениях. Для визуальной сверки использовались присланная дизайн-система и локальная разметка «Сегодня». Ветка построена от origin/main и самостоятельно собирается с ресурсами этой базы.
- Сервер компании, физический обрыв сети, Narrator и переключение системной высокой контрастности вручную не проверялись. На минимальной ширине у опубликованной общей навигации есть обрезание иконок. Оно находится за пределами рабочей области поиска.
