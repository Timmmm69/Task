# Task — автоматические напоминания 1.0.0

Клиент 1.0.10: распакуйте `client/Task-1.0.10-win-x64-unsigned.zip` и запустите `Task/Task.Desktop.exe`. При сроке автоматически появляется напоминание; выбор находится в карточке рядом со сроком. Настройки интервала и часа для даты без времени — в «Настройках». Не заменяйте отдельные DLL старого клиента: передайте весь каталог Task. Personal обновляет локальную БД штатной миграцией с резервной копией; не удаляйте пользовательское хранилище.

Corporate требует обновления серверных API/Worker/Migrator до этого же исходного коммита и PostgreSQL 16+. Перед серверным обновлением выполните принятый backup/runbook, остановите старые сервисы, примените миграцию 016 штатным Migrator, затем запустите новые API и Worker. Ограниченные runtime grants обновляются миграцией и grant-runtime.sql. Настройки исполнения/секреты передаются по существующему deployment контракту, в пакет не включены.

`server-linux-x64/` — собранные framework-dependent компоненты API, Worker, Migrator и BackupAgent (.NET/ASP.NET Core 10 runtime нужен отдельно). Linux/container runtime этих файлов здесь не проверен. `server-source.zip` содержит исходники, миграции, штатные Dockerfile/скрипты сборки и проверки; для production используйте существующий CI/container pipeline. Локальный Docker engine недоступен; проверенный OCI-релиз не заявлен.

Клиент unsigned: это привычный portable-пакет для ручной передачи, не подписанный production updater. Проверенные ограничения перечислены в validation-report.md. Бинарные payload/ZIP остаются локальными в outputs; в Git опубликованы исходники, manifest, хеши и evidence.
