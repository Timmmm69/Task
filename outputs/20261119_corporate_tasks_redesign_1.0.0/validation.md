# Проверка корпоративного экрана «Задачи»

Версия результатов 1.0.0. Проверен коммит `db4fa41` от 19 ноября 2026 года.

- Сборка `Task.Desktop.csproj`, Release, .NET 10.0.400. Ошибок и предупреждений нет.
- Целевые тесты WPF, фильтрации, сортировки, карточки, действий, статусов и доступности. 208 из 208.
- Тесты клавиатуры и поиска в палитре команд отдельным запуском. 3 из 3.
