## Поведение и устранённые дефекты

- Статус фильтруется по `DesktopTaskStatus?`, все 5 бизнес-статусов и вариант «Все статусы». Отображение «Просрочена» не меняет принадлежность бизнес-статусу.
- Проекты фильтруются по `Card.ProjectId`, включая null/«Без проекта». Одинаковые доступные названия получают нейтральные порядковые суффиксы. При недоступном имени — только «Проект назначен», без отображения ID. Используется прежний разрешённый options lookup, новый справочник или запрос не добавлен.
- Приоритет — `DesktopTaskPriority?`: Low, Normal, High, Critical, все значения.
- Срок — все, просроченные, сегодня, ближайшие 7 дней, без срока. Все четыре условия применяются пересечением к загруженному разрешённому набору.
- `DeadlineAtUtc` имеет нормативный приоритет над `Card.DeadlineDate`. UTC переводится в локальную зону пользователя (TimeProvider.System.LocalTimeZone соответствует прежнему ToLocalTime). DateOnly остаётся календарной датой. Сегодня определяется в локальной зоне пользователя.
- Просрочка использует прежний `TaskRules.IsOverdue`: точный момент либо календарная дата в `Card.DeadlineTimeZone`. Completed и Cancelled исключены.
- Семь дней: сегодня D, D+1, ..., D+6; обе границы включены. D-1 и D+7 исключены. Nullable срок не попадает в ближайшие дни.
- Временный completion feedback больше не позволяет завершённой строке обходить статусный фильтр. Серверное подтверждение, announcement, событие завершения, reduced motion и анимация видимых завершённых строк сохранены. Несоответствующая строка исчезает сразу.
- Выбор проекта сохраняется по ID при добавлении страниц и обновлении допустимых вариантов; исчезнувший вариант сбрасывается. Статус, приоритет и срок сохраняются при refresh.
- Выделенная видимая строка сохраняется, включая реальный WPF ListBox с двухсторонней привязкой. Если локальный фильтр скрывает выбранную задачу, выделение и карточка очищаются без скрытого запроса другой карточки. Reset атомарно сбрасывает все четыре фильтра.
- Новые локальные фильтры не читают сервер и не пишут offline-очередь. Обновление коллекции защищает выделение от промежуточного WPF null.
- При nextCursor: «Найдено среди загруженных задач», количество относится к загруженному набору; «Загрузить ещё» доступна даже без совпадений. Новые страницы дедуплицируются и фильтруются, ошибка сохраняет набор. Invalid cursor показывает неполноту и предложение обновить.
- Панель использует прежние ComboBox/стили, понятные подписи, UIA names/IDs и проверенный порядок Tab. Для низкого окна уменьшены только отступы экрана задач; 800×480 сохраняет видимую строку списка. Пустое состояние и footer дают сброс.
- Server, DB, OpenAPI, transitions, permissions и personal task manager не изменены. Сортировка не добавлена.

## Ограничения и возможные регрессии

Фильтрация намеренно ограничена загруженными разрешёнными страницами. Полная серверная фильтрация не существует в текущем API. Нет автоматического догружания всех страниц.
Фильтр пересчитывает календарные условия при изменении фильтров или обновлении данных; отдельный таймер смены суток не добавлялся.
Смена локального фильтра, скрывающая выбранную задачу, оставляет карточку пустой до явного выбора, чтобы offline-смена фильтра не вызывала сетевой запрос.
«Просрочена» перенесена из вариантов статуса в фильтр срока; завершённая задача больше не задерживается в несовместимом статусном фильтре ради анимации. Это намеренные UX-изменения.
Live-server ручной сценарий, Narrator и mixed-monitor DPI в этой задаче не выполнялись. Общий server/DB gate не запускался: серверная часть не менялась. В сборке остались два прежних предупреждения xUnit1031/xUnit2031 в посторонних тестах.
