## Среда и проверки

Все 3682 из 3682 тестов прошли. Task.Tests — 953, Task.ServiceHosts.Tests — 694, Task.Desktop.Tests — 2035. Пропущенных тестов нет. Дополнительно прошёл интерактивный тест отправки через Windows Shell.

Windows, .NET SDK 10.0.400, конфигурация Release. PostgreSQL 16 работал на loopback с русской ICU-локалью. Тесты создавали изолированные базы. Для личного режима использовались временные SQLite-профили.

- `dotnet build Task.sln --configuration Release --no-restore -m:1`
- `dotnet test Task.sln --configuration Release --no-build --no-restore -m:1 --logger trx`
- Штатный аудит NuGet, проверка архитектурных границ, проверка форматирования и `git diff --check`.
- Обычное и компактное окна «Сегодня» в каждом режиме отрисованы при 1180 × 800 и 820 × 600. Панель фильтров также проверена при 800 × 480. В каталоге `screenshots` снимки рабочих окон с тестовыми данными.
- Серверные HTTP-тесты проверяют привязку итогов к авторизованной учётной записи, права, границы дат и отсутствие доступа к недельной истории без разрешения. Интеграции с PostgreSQL проверяют запросы под рабочей ролью.
- `test-results.json` содержит счётчики наборов, контрольные суммы исходных файлов TRX и выборку имён целевых тестов.

## Границы проверки

Корпоративные окна открывались с тестовыми данными. HTTP и PostgreSQL проверялись отдельно. Развёртывание в корпоративной сети и доставка на другие рабочие станции в проверку не входили. Windows приняла тестовое уведомление, фактическое появление баннера при индивидуальных настройках «Не беспокоить» визуально не подтверждалось. Ветка уменьшенного движения проверена без изменения глобальных настроек Windows. Полноценный сеанс с системной контрастной темой не проводился.

Корпоративной поставке нужны соответствующие версии клиента и API с миграцией PostgreSQL 023. Личный профиль обновляется до схемы SQLite 7 при открытии. При отсутствии исторической версии для точного подсчёта итог сообщает о недостатке данных. Исходная бизнес-модель сохраняет завершённое и отменённое состояния терминальными.

Патч в файле `implementation.patch.gz` воспроизводит исходные изменения относительно указанной базы. Контрольные суммы файлов приведены в `SHA256SUMS.txt`.
