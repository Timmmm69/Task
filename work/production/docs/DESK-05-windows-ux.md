# DESK-05 — Windows UX на целевых рабочих местах

Версия реализации: 1.0.0.

## Результат

Windows-клиент Task подготовлен и нативно проверен для рабочего диапазона масштабирования
100–200%. Окна входа и основного приложения сохраняют доступ к критическим действиям, а
клавиатурная навигация и UI Automation предоставляют предсказуемый маршрут управления.

## Реализованный контракт

- приложение объявляет `PerMonitorV2` и `PerMonitor` DPI awareness в Windows manifest;
- стартовый размер обоих окон ограничивается доступной рабочей областью текущего Windows-экрана;
- минимальный размер окна входа допускает эквивалент 200% для базового viewport 1920×1040;
- форма входа использует циклический `Tab`-маршрут, доступные имена и заголовки UIA;
- основное окно поддерживает `F6`-цикл «навигация → команды заголовка → содержимое»;
- основные области, команды, список задач, статусы подключения и заголовки имеют стабильные
  AutomationId, доступные имена и семантические свойства;
- статус подключения объявлен как live region; если конкретный UIA-клиент Windows не перечисляет
  `LiveSetting` для `TextBlock`, декларативный XAML-контракт всё равно проверяется source-тестом;
- тестовый desktop data directory можно изолировать через `TASK_DESKTOP_DATA_DIRECTORY`, поэтому
  нативная проверка не изменяет пользовательские credentials и server settings.

## Воспроизводимая проверка

Запуск из корня репозитория в Windows PowerShell:

```powershell
& .\work\production\verification\Test-Desk05WindowsUx.ps1
```

Runner собирает Release-решение, запускает семь целевых тестов, поднимает изолированные
PostgreSQL 16 и HTTPS API, открывает реальные WPF-окна и проверяет их через Windows UI Automation.
Для 100/125/150/200% он меняет нативный размер окна до логического эквивалента базового viewport,
проверяет границы критических элементов и сохраняет скриншоты. После проверки runner останавливает
только созданные им процессы и удаляет только свой изолированный runtime.

Итоговый прогон от 10 сентября 2026 года:

- Windows build `10.0.26200.0`, экран 2560×1600, фактический DPI основного окна 144 (150%);
- Release build: 0 ошибок, 0 предупреждений;
- целевые тесты: 7/7;
- нативные проверки: 86/86;
- UIA Value/Invoke/Selection, `Tab` и полный `F6`-цикл: PASS;
- обе матрицы 100/125/150/200% и восемь визуально проверенных PNG: PASS.

Машиночитаемый результат: `work/production/evidence/desk05/windows-ux.json`.

## Границы доказательства

Проверка экранными дикторами не входит в acceptance scope продукта Task. Фактический монитор
стенда работал при 150%; остальные значения проверены как эквивалентные логические viewport на
том же нативном PerMonitorV2 WPF-окне.
Приёмка конкретного парка устройств (драйверы, несколько физических мониторов и политики Windows)
остаётся стандартным deployment smoke, а не незавершённой частью реализации DESK-05.
