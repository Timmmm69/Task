# Object Links 10.1–10.3 — открытая ручная приёмка

**Статус: OPEN / НЕ ПРОЙДЕНА.**

Пользователь разрешил публикацию 10.1–10.3 в main 2026-10-17 с сохранением
этого открытого пункта. Публикация кода и успешные автоматические тесты
не закрывают ручную приёмку.

Коммит `402483b` устраняет три прежних ограничения: отдельный discovery endpoint
без Search.Use, полный набор related targets и чтение всех страниц связей.
Текущий контракт описан в [OBJECT-LINK-TARGET-DISCOVERY.md](OBJECT-LINK-TARGET-DISCOVERY.md).
Отчёт 10.3.0 является историческим снимком до этих исправлений.

## Что нужно открыть и проверить позже

Использовать установленный Windows-клиент и реальный Corporate API с одинаковой
версией нового endpoint. Зафиксировать версии, роли, ОС, DPI и результаты;
не включать реальные токены, пароли и конфиденциальные данные в evidence.

- [ ] Установленный клиент: выбор source в WorkHub/контактах/каталоге/поиске,
  выбор target по названию, одинаковые/длинные названия, подтверждение реального ID.
- [ ] Корпоративный API: разрешённые типы связей, дополнительные related targets,
  создание без Search.Use при ObjectLink.Create и соответствующих read permissions.
- [ ] Реальные роли: независимые Create/Delete, own-scope notification/inbox,
  отсутствие чужих tenant/object результатов, отзыв прав и завершение сессии.
- [ ] Подтверждённые create/list/delete, список более 200 связей, конфликт версии,
  исчезновение source/target, offline/reconnect и повтор после неопределённой записи.
- [ ] Физическая клавиатура: Tab/Shift+Tab, Enter/Escape, видимость и сохранение фокуса.
- [ ] Запущенный Narrator: слышимые имена/типы найденных объектов и изменения статуса;
  отсутствие лишнего озвучивания UUID и потери контекста.
- [ ] Mixed-DPI: перенос окна между мониторами разного масштаба, узкое окно,
  отсутствие обрезанных кнопок, текста, фокуса и недоступных действий.
- [ ] Personal Mode без Corporate-сервера: source/target, save/delete и сохранение данных.

## Условия закрытия

Для каждого пункта записать PASS/FAIL, шаги, фактический результат и ссылку на evidence.
При FAIL завести конкретный дефект и оставить этот документ OPEN. Закрывать пункт
в dashboard и менять статус на PASSED только после фактической проверки всех пунктов.

Результаты автоматических прогонов публикации находятся в
`outputs/20261017_object_links_publication_10.3.1/validation-report.json`.
