# DESK-01 — безопасное подключение и вход, версия 1.0.0

Windows-клиент завершает полный сотруднический auth-сценарий: принимает только абсолютный HTTPS-адрес сервера без query, fragment и user info; проверяет `/health/live` и `/health/ready` без отключения TLS; выполняет вход с зарегистрированным Windows-устройством; подтверждает серверную сессию перед открытием рабочего окна; восстанавливает её после перезапуска; принудительно проводит смену временного пароля; завершает серверную и локальную сессии при выходе.

## Границы безопасности

- Пароль не сохраняется. Access token существует только в памяти процесса.
- Refresh token, device key и связанная identity сохраняются через Windows DPAPI для текущего пользователя; запись атомарна, повреждённый payload изолируется и не используется.
- Main shell не открывается до успешного `GET /api/v1/auth/session` и не открывается при `mustChangePassword=true`.
- Terminal состояния `SESSION_EXPIRED`, `SESSION_REVOKED`, `REFRESH_TOKEN_REUSE`, блокировка аккаунта и отзыв устройства очищают локальную сессию.
- Сетевой сбой не трактуется как успешный вход: vault сохраняется только там, где допустим повтор восстановления, а основной интерфейс остаётся закрытым.
- Смена сервера сначала удаляет локальную сессию прежнего endpoint. Выход очищает локальные данные даже при недоступном сервере.

## Эксплуатационная выдача учётной записи

Зависимость закрыта реализацией API-01. Публичной регистрации нет. Администратор создаёт pending account, выдаёт временный пароль, активирует аккаунт и при необходимости блокирует, деактивирует, повторно активирует или сбрасывает пароль. Временный пароль действует 24 часа и требует смены до доступа к рабочим операциям. Reset, block, deactivate и revoke отзывают соответствующие серверные сессии и refresh tokens.

## Проверка

Команда полного воспроизводимого gate из корня репозитория:

```powershell
pwsh -NoProfile -File work/production/verification/Test-DesktopAuth.ps1
```

Gate запускает полный solution regression с отдельным PostgreSQL 16, затем проверяет в TRX наличие и успешность ключевых сценариев DESK-01. Для повторной проверки уже полученных TRX без нового запуска используется `-SkipTestRun`.

Исторический ручной E2E через реальное WPF-окно, доверенный localhost HTTPS API и PostgreSQL включён в итоговый пакет. Текущий автоматический gate покрывает последующие изменения desktop workflow/session client и завершённый account lifecycle API-01.
