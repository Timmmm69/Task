# Dashboard готовности Task

## Как запустить

1. Откройте PowerShell в корне проекта.
2. Выполните `npm run dashboard`.
3. Если браузер не открылся сам, перейдите на `http://127.0.0.1:4178`.

Dashboard работает только на этом компьютере и не отправляет данные во внешние сервисы.

## Откуда берётся процент

Источник истины: `.project-dashboard/roadmap.json`. Общая готовность считается автоматически по формуле `SUM(weight * progress) / SUM(weight)`. Допустимы только значения progress 0, 25, 50, 75 и 100. Статус передачи отдельно определяется обязательными release gates, поэтому высокий процент сам по себе не означает готовность.

Очередь работ считается отдельно от процента. Каждый пункт хранит priority, dependencies, blocked_by, recommended_order и next_action. Алгоритм сначала соблюдает зависимости, затем учитывает приоритет, критичность, риск неизвестности, число разблокируемых работ и уже достигнутый progress.

Git status и последние commits считываются локально при каждом обновлении страницы. Тесты не запускаются автоматически: показывается последний сохранённый результат из `test-results.json`.

## Как обновляется

Открытая страница запрашивает свежие данные раз в 5 секунд. После обычной задачи Codex должен менять только затронутые пункты roadmap и добавлять фактическое evidence.

После изменения progress/status выполните `npm run dashboard:order`. Команда пересчитает recommended_order без повторного анализа репозитория и покажет новую задачу «Сейчас».

Если автоматическая синхронизация Codex не сработала, попросите: «Обнови затронутые пункты readiness dashboard по результату последней задачи». Полный повторный анализ репозитория для этого не нужен.

Project-local Codex Stop hook не добавлен: на момент создания dashboard официальный механизм `.codex/hooks.json` не был подтверждён доступной официальной документацией или текущим окружением. Dashboard полностью работает без hook благодаря live git telemetry и polling JSON.

## Проверка

Запустите `npm run dashboard:validate`. Команда проверяет схему, 30-50 delivery units, вычисления процентов, release gates, test totals и наличие интерфейса.
